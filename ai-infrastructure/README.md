## The call, in one line
Demand keeps soaring *through 2026* — but mostly in **price/backlog, not deployed units** (physical
bottlenecks ration supply); **memory is the strongest "beyond expectations" leg** while Nvidia's
*share* is the eroding risk; and the whole web is a **hub-and-spoke bet on OpenAI**, so the thing
that breaks it is a financing/ROI event at the hub, not a demand cliff — with 2027–28 carrying a
real overbuild-whipsaw risk (because *dark GPUs don't hold option value like dark fiber did*).
